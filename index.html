🔌 What is this? An MCP (Model Context Protocol) Server exposes tools, resources & prompts that any AI agent (Claude, GPT, etc.) can call using a standardized protocol — like a USB interface between LLMs and real-world systems. This POC wraps real IT incident workflows. Tools: 4 Resources: 3 Prompts: 2 Transport: stdio / HTTP+SSE
