LangGraph Orchestrator — StateGraph Controller
Manages agent state, routes between nodes, handles conditional edges based on triage priority. Uses supervisor pattern — all agents report back to orchestrator before next step executes.
START → TriageAgent → KnowledgeAgent → EnrichmentAgent → ValidationAgent → END
🚨
TriageAgent
langgraph.node · tools: [triage_incident] · model: gpt-4o
IDLE
Classifies incident priority, identifies category, matches similar past incidents. Calls triage_incident MCP tool and decides if escalation to P1 is needed.
⚡ MCP Tool: triage_incident → IncidentMCPServer
◦Receive incident state from orchestrator
◦Call MCP tool: triage_incident(incident_id, description)
◦Parse priority, category, confidence_score
◦Update shared state: {priority, category, assignment_group}
◦Route to KnowledgeAgent via conditional edge
🔍
KnowledgeAgent
langgraph.node · tools: [search_knowledge] · model: gpt-4o
IDLE
Performs RAG-based knowledge retrieval using triage context. Fetches relevant KB articles, runbooks, and past incidents from Pinecone vector DB via MCP.
⚡ MCP Tool: search_knowledge → Pinecone RAG
◦Read triage context from shared agent state
◦Call MCP tool: search_knowledge(category + description)
◦Retrieve top-5 matches from Pinecone (min_score: 0.75)
◦Re-rank results using LLM relevance scoring
◦Update state: {kb_articles, runbooks, similar_incidents}
🧩
EnrichmentAgent
langgraph.node · tools: [enrich_ticket, generate_rca] · model: gpt-4o
IDLE
Auto-fills ServiceNow/JIRA fields with structured data and drafts initial RCA. Uses all prior agent context (triage + knowledge) to produce rich ticket enrichment.
⚡ MCP Tools: enrich_ticket + generate_rca
◦Read full state: triage + knowledge results
◦Call MCP tool: enrich_ticket(raw_description, context)
◦Push structured fields to ServiceNow REST API
◦Call MCP tool: generate_rca(incident_id, resolution_context)
◦Update state: {enriched_ticket, rca_draft, snow_updated}
✅
ValidationAgent
langgraph.node · tools: [incident://metrics] · model: gpt-4o
IDLE
Final quality gate — validates all agent outputs, checks SLA compliance, confirms assignment group, and produces the final actionable incident resolution package.
⚡ MCP Resource: incident://metrics · Tool: incident_summary
◦Review all agent outputs in shared state
◦Validate: priority, category, assignment_group consistency
◦Fetch live SLA data via MCP resource: incident://metrics
◦Generate exec-ready summary via MCP prompt
◦Return final resolution package → END node
